Doorbellr is a smart doorbell that, for a small monthly fee, instantly calls your phone to tell you someone just rang your doorbell, which you already heard because you were standing right next to it.

## Run

```sh
node main.ts
```

`main.ts` writes the one-sentence pitch to `output/entry.txt` (or `/output/entry.txt` when the grading sandbox provides it), reads it back to verify it byte for byte, and prints its character count and sha256.
